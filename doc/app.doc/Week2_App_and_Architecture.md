# System & Architecture Documentation
**โปรเจกต์:** เว็บแอปพลิเคชันสำหรับประมวลผลรูปภาพ วิดีโอ และตรวจจับวัตถุด้วย AI  
**ผู้ออกแบบและจัดทำระบบ:** Punpun (MOJOEA)

---

## ภาพรวมและสิ่งที่คุณสมบัติไฟล์นี้ระบุ (What this System Does)
ระบบนี้ถูกออกแบบขึ้นมาเพื่อทำหน้าที่เป็น **ตัวกลางอัจฉริยะ (System Gateway & Interface)** ในการรับไฟล์สื่อมวลชน (ภาพถ่าย/วิดีโอ) จากผู้ใช้งาน นำมาผ่านกระบวนการปรับปรุงคุณภาพภาพหลังบ้าน และส่งต่อไปให้โมเดลปัญญาประดิษฐ์ (AI Model) ประมวลผลทำนายวัตถุ ก่อนจะดึงข้อมูลพิกัดเชิงลึกกลับมาแสดงผลบนหน้าเว็บเบราว์เซอร์แบบ Real-time 

ระบบถูกแยกโครงสร้างออกจากกันอย่างเด็ดขาดในรูปแบบ **Modular Design** เพื่อให้ง่ายต่อการทำงานร่วมกับทีมพัฒนาโมเดล AI ในอนาคต

## สิ่งที่ระบบจัดทำและพัฒนาไปแล้ว (Implementation Log)

ในการวางโครงสร้างและเขียนโค้ดระบบหลังบ้าน คุณได้วางรากฐานและพัฒนาฟังก์ชันสำคัญต่างๆ ไว้เรียบร้อยแล้ว ดังนี้:

### 1. การวางโครงสร้างสถาปัตยกรรมหน้าเว็บ (Multi-page Routing)
*   **ระบบคุมทิศทางหน้าเว็บ (`app.py`):** ลงมือเขียนระบบแยกหน้าการทำงานหลักออกเป็นส่วนๆ ผ่านคำสั่ง `st.Page` และ `st.navigation` 
*   **แบ่งหน้าต่างการทำงานชัดเจน:**
    *   **ระบบหลัก (`detection_page.py`):** หน้าสำหรับโหลดโมเดล อัปโหลดไฟล์ และแสดงผลการตรวจจับวัตถุ
    *   **รายงานและสถิติ (`dashboard_page.py`):** หน้าต่างว่างที่เตรียมไว้สำหรับประมวลสถิติเชิงลึก

### 2. ระบบจัดการหน่วยความจำโมเดล (Resource Caching)
*   **เขียนฟังก์ชัน `load_model`:** ผูกตัวแปรโมเดล YOLO เข้ากับคุณสมบัติ `@st.cache_resource` ของ Streamlit 
*   **ผลลัพธ์ที่ได้:** ระบบจะโหลดโมเดลตัวหนักจากดิสก์เข้าสู่ RAM เพียงแค่ **"ครั้งแรกครั้งเดียว"** เท่านั้น เมื่อผู้ใช้งานกดปุ่มหรือตั้งค่าหน้าเว็บใหม่ ระบบจะไม่ทำซ้ำ ส่งผลให้เว็บทำงานเร็วและไม่กินทรัพยากรเครื่อง

### 3. ระบบควบคุมการไหลและการประมวลผลไฟล์ (Core Core Processors)
*   **การแปลงไฟล์ภาพดิบ (`process_image_file`):** เขียนโค้ดสตรีมไฟล์ให้อยู่ในรูป Matrix Array ผ่าน `cv2.imdecode` เพื่อให้ OpenCV นำไปคำนวณต่อได้ พร้อมแปลงพื้นที่ช่องสี (Color Space) กลับไปมาระหว่าง BGR และ RGB เพื่อให้ภาพแสดงสีสันบนเว็บได้อย่างถูกต้อง
*   **การประมวลผลวิดีโอด้วยเทคนิคข้ามเฟรม (`process_video_file`):** พัฒนาระบบ `tempfile` เพื่อแปลง Byte Stream ของไฟล์วิดีโอที่ถูกส่งขึ้นมาบนหน้าเว็บ ลงไปเขียนเป็นไฟล์ชั่วคราวบนดิสก์ เพื่อส่ง Path ต่อให้โครงสร้างคำสั่งอ่านวิดีโอทำงานได้

## สิ่งที่มีให้ใช้งานและฟีเจอร์ระบบ (Available Features)

บนหน้าต่างอินเตอร์เฟสควบคุม มีฟังก์ชันและพารามิเตอร์ที่เปิดให้ผู้ใช้งานหรือผู้ตรวจสอบระบบกดปรับแต่งได้แบบทันทีผ่าน Sidebar ดังต่อไปนี้:

*   **เปิด/ปิดระบบลดสัญญาณรบกวน (Denoise Toggle):** สวิตช์ Checkbox ควบคุมตัวแปร `enable_denoise` เพื่อสั่งการให้ฟังก์ชัน `preprocess_frame` ตัด Noise หรือสิ่งรบกวนออกจากภาพหรือวิดีโอก่อนจะส่งไปให้ AI อ่าน ช่วยเพิ่มความแม่นยำในการตรวจจับวัตถุในสภาวะแสงไม่พึงประสงค์
*   **ปรับขนาดการแสดงผลบนหน้าจอ (Dynamic Scaling Slider):** แถบเลื่อนปรับแต่งขนาดภาพฝั่งรับเข้าและผลลัพธ์การแสดงผล (พิกเซล) ตั้งแต่ **200px ถึง 1200px** โดยใช้กลไกการฉีดสไตล์ซีเอสเอส (`load_css`) เข้าไปคุมความกว้างหน้าเว็บ ทำให้ปรับขนาดบล็อกภาพได้ยืดหยุ่นโดยไม่พังโครงสร้างส่วนอื่น
*   **ระบบปรับความเร็วและข้ามเฟรมวิดีโอ (Video Speed Control):** แถบเลือกสปีดระดับการอ่านเฟรม ตั้งแต่ **1x, 1.25x, 1.5x, 1.75x จนถึง 2x** 
    *   *กลไกภายใน:* ตัวควบคุมความเร็วนี้จะส่งค่าตัวคูณความเร็ว (`speed_multiplier`) เข้าไปคิดคำนวณหาค่าระยะข้ามเฟรม (`skip_interval`) 
    *   หากเลือกความเร็วสูงขึ้น ระบบจะใช้ชุดคำสั่ง `continue` ข้ามเฟรมที่ไม่ได้อยู่ในช่วงทิ้งห่างไปทันที ส่งผลให้ AI ไม่ต้องทำงานหนักทุกเฟรม และช่วยลดการหน่วงของหน้าเว็บลงได้อย่างมหาศาล
*   **ระบบรองรับการตรวจจับแบบเป็นกลุ่ม (Batch Processing):** หน้า UI ถูกตั้งค่าพารามิเตอร์ `accept_multiple_files=True` ทำให้ผู้ใช้งานสามารถลากรูปภาพหลายๆ รูปมาวางในกล่องอัปโหลดได้พร้อมกัน โดยระบบจะใช้ลูปประมวลผลทีละไฟล์แยกแถวกันอย่างเป็นระเบียบ
*   **หน้าต่างข้อมูลพิกัด (JSON Data Expander):** สำหรับนักพัฒนาหรือผู้ตรวจสอบ โค้ดหลังบ้านจะทำการจัดฟอร์แมตข้อมูลวัตถุที่ตรวจจับเจอ เช่น ชื่อคลาส เปอร์เซ็นต์ความมั่นใจ และพิกัดกรอบล้อมรอบวัตถุ ($X_{min}, Y_{min}, X_{max}, Y_{max}$) ให้ออกมาเป็นโครงสร้างข้อมูลมาตรฐาน และซ่อนไว้ในกล่อง `st.expander` เพื่อไม่ให้บดบังทัศนวิสัยบนหน้าเว็บ

## รายละเอียดฟอร์แมตข้อมูลส่งออก (JSON Data Structure)
นี่คือตัวอย่างโครงสร้างข้อมูลรูปแบบ JSON ที่ระบบฝั่งจัดทำสถาปัตยกรรมของคุณ ได้วางระบบสกัดออกมาจากตัวแปรตรวจจับของ AI เพื่อพร้อมส่งต่อไปใช้งานต่อ:

```json
[
  {
    "class": "ชื่อคลาสวัตถุที่ตรวจจับได้ (string)",
    "confidence": 0.999, // ค่าความมั่นใจปัดเศษทศนิยม 3 ตำแหน่ง (float)
    "bbox": [100.5, 50.0, 300.2, 400.1] // พิกัดกรอบ [Xmin, Ymin, Xmax, Ymax] ปัดเศษ 1 ตำแหน่ง
  }
]
```
